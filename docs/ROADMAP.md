# AvLü™ | Public development roadmap

**Version v1.0.0 | Product research and implementation priorities**

| Priority | Workstream | Public acceptance concept |
| --- | --- | --- |
| 1 | Evidence quality | Clear source provenance, data conflicts, and unknown-state handling |
| 2 | Screening reliability | Repeatable calculations, policy boundaries, and reviewable explanations |
| 3 | Outcome calibration | Reliable links between prior observations and verified disposition outcomes |
| 4 | Workflow validation | Compare the tool with a real user's existing process in an approved pilot |
| 5 | Controlled automation | Only after source rights, data quality, approvals, security, and rollback controls are demonstrated |

These are **priorities**, not a claim of deployed integrations or agreed customer pilots. I will publish demonstrated milestones separately from proposed ones.
