# Synthetic showcase demo

**v1.0.0**

I built a lightweight interactive explanation of the AvLü review states. Launch by opening `index.html` directly in a modern browser.

The examples are fictional, with fixed display values. Clicking a card changes the prewritten record shown on screen. This demo **does not execute underwriting, source lookup, recalculation, API requests, or transactions**. Numbers are illustrations only.

For a technical mentor walkthrough:

1. Explain the incomplete-listing problem.
2. Open the synthetic demo and select an example.
3. Point out missing evidence before discussing hypothetical resale potential.
4. Open [architecture overview](ARCHITECTURE.md).
5. Close with the [specific review questions](TECHNICAL_REVIEW.md).

Do not use the demonstration for actual purchase, offer, appraisal, title, or legal decisions.
