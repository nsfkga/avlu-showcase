# Questions for technical reviewers

**Version v1.0.0 | Owner: Nathaniel Schroeder**

I am looking for candid, actionable criticism rather than general encouragement. The most useful review would focus on these questions:

1. **Data quality:** What approaches would you use to reconcile inconsistent listings and assign explicit confidence without overstating the evidence?
2. **Source rights:** How should I prioritize stable and permitted data sources instead of brittle collection methods?
3. **Auditability:** What minimal provenance and versioning details should be retained for every screening decision?
4. **Safety:** What architecture should prevent an incomplete estimate from silently becoming an executable acquisition action?
5. **Outcome linkage:** How should a prior market observation be associated with a verified completed sale without introducing false matches?
6. **Operational value:** What pilot design could compare the workflow against existing dealer tools and manual review fairly?
7. **Maintainability:** Which parts should be deterministic and testable, and where does AI extraction genuinely help?

I can discuss deeper implementation under an appropriate confidential review arrangement. Please do not post credentials, customer records, private seller details, or unreleased algorithms in public issues.
