# AvLü™ | Buyer ROI and pilot measurement method

**Pilot experiment design | v1.0.0 | October 15, 2026**  
**Founder and owner: Nathaniel Schroeder**

## The commercial question

If someone can already use a dealer system, price guide, AI and spreadsheet, why subscribe to AvLü? The answer must be in their actual workload and economic outcomes, not an invented return-on-investment headline.

## Run the comparison fairly

For five to ten authorized, closed historical buyer decisions in one initial vehicle/equipment/attachment category and defined permitted source channel:

1. Reconstruct only the source facts and costs known **at the time of the purchase decision**, not information learned afterward.
2. Record how long the original buyer workflow took, including searches, calls, record entry and errors discovered later.
3. Repeat the same cases through the scoped AvLü workflow and a reasonably equipped incumbent/general-AI alternative.
4. Include inaccurate model matches, missing condition flags, unnecessary HOLDs, unrecognized expenses and unsupported comparable sales.
5. Compare independently verified outcomes only where matching actual acquisition/sale paperwork exists.
6. Count all new administrative burden and founder/manual assistance. A faster-looking UI with hidden labor is not a scalable SaaS benefit.

## Metrics and calculations

| Measure | Method | Caution |
| --- | --- | --- |
| Review minutes saved | Existing review time minus AvLü-assisted time, same case | Include setup and corrected errors |
| Buyer labor value | Minutes saved / 60 × documented fully loaded hourly labor rate | Capacity released is not automatically cash savings |
| Material omissions | Consequential costs/evidence the existing process missed that AvLü flagged correctly | Independently verify importance and avoid hindsight |
| False HOLD rate | Unsupported blocks / cases reviewed, with reasons | Excessive holds can harm customers |
| Estimate error | Estimated total cost minus actual total cost when documented | Not computable without matched invoices |
| Repeat usage | Unprompted return with a second or later case | Founder-run demonstrations alone are weak |
| Unit servicing cost | Real direct data, inference, support and integration cost per buyer/month | Do not ignore human analyst work |
| Real customer willingness to pay | Paid pilot, repeat payments and renewals | Survey enthusiasm is not revenue |

## Illustration only

If a dealer reviews 30 potential lots per month and a carefully measured pilot finds 12 minutes of net time saved per review, that would release **6 labor hours per month**. At a hypothetical $45/hour fully loaded wage, the *imputed* labor value would be $270/month. It is **not** established cash saved or AvLü profit. Additional software costs, integration and errors must be subtracted to estimate net value.

If the proposed Independent subscription is $199/month, this example alone may not create a sufficient margin of value. The buyer could still prefer a competing tool, need a lower price, or value fewer costly buying mistakes much more than time savings. That is a commercial discovery question.

## Decision rules

Stop or narrow if the source data is inaccessible, comparisons are inconclusive, false HOLDs burden users, or the buyer cannot justify the price relative to existing solutions. Continue to full paid testing only when buyer value can be observed and the direct customer support cost appears sustainable.

No real dealer outcome, completed transaction, pricing acceptance or investor return is claimed by this illustrative method.
