# Security and privacy scope

**Version v1.0.0**

This repository hosts a stand-alone synthetic presentation, not a production service. It has no accounts, network requests, database, tokens, or executable acquisition controls.

Please do not submit credentials, customer records, identifying seller data, or private business information in public GitHub issues. For sensitive reports or confidential review requests, contact me through https://getavlu.com.

This document does not represent a security audit of the private application. Security of that separately maintained application is not established by these synthetic showcase files.
